# Degga Beer — MVP do painel de gestão

Demonstração front-only (Next.js + shadcn + zustand): PDV, estoque, produtos/kits/drinks e financeiro.
Dados fictícios guardados no navegador.

```bash
pnpm install
pnpm dev   # http://localhost:3000 → escolha um perfil (Dono, Gerente ou Caixa)
```

Deploy: Vercel, import do repositório, sem variáveis de ambiente.
